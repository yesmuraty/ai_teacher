# 🎓 Тілдік дағдылар боты

8-сынып оқушыларының тілдік дағдыларын дамытуға арналған Telegram боты.

## 📦 Орнату

```bash
pip install -r requirements.txt
```

## ⚙️ Баптау

`config.py` файлын ашып:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"   # @BotFather-дан алынған токен
TEACHER_SECRET_CODE = "mugalim2024"  # Мұғалімдер үшін жасырын код
```

## 🚀 Іске қосу

```bash
python main.py
```

## 👩‍🏫 Мұғалім функционалы

1. `/start` → "Мен мұғаліммін" → Жасырын код енгізу → Аты-жөні
2. **Тапсырма қосу**: дағды таңдау → атау → мазмұн (мәтін/фото/файл/дауыс)
3. **Тапсырылған жұмыстар**: оқушы жұмысын көру → баға қою (2-5) → пікір жазу
4. Оқушыға автоматты хабарлама жіберіледі

## 👨‍🎓 Оқушы функционалы

1. `/start` → "Мен оқушымын" → Мұғалімді таңдау → Аты-жөні
2. Дағды таңдау: 🎧 Тыңдалым / 🗣 Айтылым / ✍️ Жазылым / 📖 Оқылым
3. Тапсырманы таңдап, мазмұнын көру
4. Жұмысты тапсыру: мәтін / фото / дауыс хабарлама
5. Мұғалімге автоматты хабарлама жіберіледі

## 📁 Файл құрылымы

```
language_bot/
├── main.py              # Бот жүргізуші
├── config.py            # Баптаулар
├── requirements.txt
├── database/
│   └── db.py            # SQLite операциялары
├── handlers/
│   ├── common.py        # /start
│   ├── teacher.py       # Мұғалім логикасы
│   └── student.py       # Оқушы логикасы
└── keyboards/
    └── kb.py            # Барлық батырмалар
```

## 🗄️ Дерекқор кестелері

- `teachers` — мұғалімдер
- `students` — оқушылар (мұғалімге байланған)
- `tasks` — тапсырмалар (дағды + мазмұн)
- `submissions` — тапсырылған жұмыстар + бағалар
